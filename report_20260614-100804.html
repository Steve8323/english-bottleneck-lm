An LLM that can only reason in English — between every layer

The residual stream is a distribution over real English words. After every layer the state is committed to words and passed through a fixed, meaning-preserving / surface-randomizing paraphrase channel before the next layer can read it. Guarantee: the only thing crossing a layer boundary is the meaning of the emitted words — any private code is destroyed. Run: full · device cpu · 4 layers · vocab 106 (24 meaning classes) · wall 304s.

1 · Capability — does the bottleneck cost performance?

Meaning-based multi-hop reasoning (Task M) is unaffected by paraphrase strength and matches the continuous transformer. A task that requires smuggling surface across layers (Task S) collapses toward chance as ρ→1 — the cost falls only on illegible channels.

2 · Covert side-channel capacity

Holding the overt meaning fixed, can a colluding sender/receiver pass a secret bit across the 4 layers via synonym choice? Both an optimal reader (worst-case bound) and a trained colluding pair fall to chance (0.5) as ρ→1. The channel is closed structurally, not by penalty.

5 · Paraphraser cost

The whole point of making the paraphraser tiny: closing the lexical channel needs only a fixed class-structured permutation — no model, no forward pass. Measured: fixed paraphrase 0.067 ms/batch vs a model layer 4.8 ms/batch — the model is 72× more expensive. The paraphraser is essentially free.
